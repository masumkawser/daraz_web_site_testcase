Test Description for Daraz E-commerce Website
Objective:
To ensure the functionality, performance, and user experience of the Daraz e-commerce website using Jira for issue tracking, Postman for API testing, and manual testing for UI/UX and end-to-end functionalities.

Tools:
Jira: For logging and managing bugs, tasks, and test cases.
Postman: For testing APIs related to product search, cart management, and order processing.
Manual Testing: For verifying UI elements, navigation, checkout flow, and responsiveness.
Test Scope:
Homepage & Search Functionality

Verify homepage loads correctly across devices.
Test the search bar for accuracy of product searches.
Product Details Page

Ensure product details (price, description, stock) are displayed accurately.
Test "Add to Cart" and "Wishlist" functionalities.
Cart and Checkout

Add items to cart and ensure the total price is calculated correctly.
Verify the checkout process (address, payment, and confirmation).
API Testing (Postman)

GET request for product listing.
POST request for placing orders.
PUT request for updating user profile.
Login/Signup

Test login and signup flows (email, social login, and OTP).
Payment Gateway

Ensure integration with payment gateways works seamlessly with multiple payment methods (e.g., card, mobile wallets).
Order History

Verify that users can view past orders and details in their order history.
Notifications

Check for proper functionality of email and SMS notifications for order confirmations.
Reporting:
Jira: Log defects and track their status using Jira workflows (open, in-progress, resolved, closed).
